# FFBackend - Fast & Flexible Backend API

A robust Node.js/Express backend server providing RESTful API endpoints.

## 🚀 Features

- RESTful API architecture
- Express.js server with middleware support
- Environment-based configuration
- Modular route structure
- JSON response formatting

## ⚡ Quick Start

1. *Clone the repository:*
```bash
git clone https://github.com/Fanitu/FFBackend.git
cd FFBackend

npm install

# Development mode
npm run dev
# Production mode
npm start

FFBackend/         # Configuration files
├── controllers/     # Route controllers
├── middleware/      # Custom middleware
├── models/         # Data models
├── routes/         # API routes          # Express app setup
├── index.js       # Server entry point
└── package.json    # Dependencies
